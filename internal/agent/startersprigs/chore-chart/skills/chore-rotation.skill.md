id: chore-rotation
name: Chore rotation
description: Use when the household sets up chores, asks whose turn it is, swaps a chore, or when the Sunday chore chart routine runs.
---
Needs: family memory (the chores and the rotation are kept there). The calendar for step 3.

1. If there's no rotation yet, ask for the chores, how often each happens, and who's in the rotation. `remember` it for the family as one line per chore.
2. Work out whose turn each chore is this week by moving the rotation on one place from last week.
3. Read the calendar for the week: if someone is away on a chore's day, swap with the next person and note the swap so it evens out next week.
4. Send the week as one line per chore: who, what, which day.
5. When someone asks for a swap, say what they'd owe back to keep it fair, and update the memory once they agree.

Done when: everyone in the rotation has their chores for the week, and the memory says whose turn is next.

Watch out:
- Be strictly fair: equal turns over a few weeks, and say why a swap is fair.
- One reminder per chore, never more. Chasing is the grown-ups' call.
- Kids are in the rotation by name, but the chart goes to the grown-ups.
- In a routine run with no rotation set up, call `nothing_to_report`.
